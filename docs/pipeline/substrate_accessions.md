## Substrate accessions

For code, see `enzyextract/pipeline/thesaurus/substrate/*`. 

Generally, we use PubChem FTP to obtain all substrate synonyms. We use the version with filtered names.

Please refer to the following resources:

- https://jcheminf.biomedcentral.com/articles/10.1186/s13321-024-00868-3
- https://ftp.ncbi.nlm.nih.gov/pubchem/Compound/Extras/
- https://ftp.ncbi.nlm.nih.gov/pubchem/Compound/Extras/README-Extras


In addition, we use BRENDA's mapping between ligand names, BRENDA ID, and InChI.
